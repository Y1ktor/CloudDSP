# Archived projects

This directory retains earlier CloudDSP implementations in version control.
Each project has a README recording its original locations, retained source,
assets, and dependencies. Archived code is outside the active frontend and
deployment build contexts.

- [EQ prototypes](eq/README.md): the standalone JavaScript equalizer and its
  later React wrapper.
- [DSP experiments and cloud prototypes](dsp/README.md): retained host analysis
  scripts, manual effect checks, and unprovisioned or superseded cloud handlers.
