# Kubernetes agent guide

[`AGENTS.md`](AGENTS.md) is the canonical scoped instruction file for this
deployment track. It cross-references the preserved cloud deployment rules and
defines the local Kubernetes boundaries.

## Learning and task scope

Document Kubernetes code and configuration with meaningful inline explanations
so the resource structure and non-obvious decisions are clear to a learner.

Work on one small, specific task at a time. When a request is broad or combines
multiple tasks, stop before changing files, propose the smallest ordered task
breakdown, recommend the first task, and wait for the user's next specific
instruction.
