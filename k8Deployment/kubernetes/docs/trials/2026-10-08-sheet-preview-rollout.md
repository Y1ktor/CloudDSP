# MIDI-to-sheet score preview rollout — 2026-10-08

## Changes

- Queue sheet moved from the file picker to the right end of the MIDI
  timeline transport, replacing its playback status. It exports the current
  notes, BPM, and meter; parsing and upload/authentication still gate submission.
- Completed jobs show their PDF below the editor, with page navigation,
  a completion heading, Open PDF, and Download MusicXML.
- PDF.js 6.4.299 loads only for completed sheets. Its worker is bundled on the
  same origin and its single canvas is capped at four million pixels. Viewer
  cleanup cancels transfers/rendering and disposes the document/worker when
  changing jobs, studios, or accounts. Artifact requests use `cache: no-store`.
- Existing CSP remains unchanged, including `frame-src 'none'`,
  `object-src 'none'`, and no unsafe script evaluation.
